## How to add file in git by VS_CODE
  git add  . => it add everything
  
  git add [ FILE NAME ] => it add specific file or folder.
  git status => it show the status of branch.
  
  git commit -m "[ FOLDER NAME ] folder with test files" => This commit contains the [Folder Name] folder and some test files.
  git commit -m "Add [ FOLDER NAME ] folder and read.txt" =>  This commit specifically adds the [Folder Name] folder and the file [File Name.txt].                      
  
  git push

## Since you modified "FILE NAME" just need to stage → commit → push the change.
  git add FOLDER NAME/ FILE NAME.txt
  git status
  git commit -m "Update FILE NAME.txt"
  git push

## local copy and GitHub are now different.
  git pull
